Map your app with Floorplan

Ask Claude for a map of your app's code. You get every part, file and connection drawn on one page, each named in plain English.

Floorplan is made by Hayden Smith. It is free and open source (MIT licence).
github.com/haydenschmitty/floorplan. All credit to him; this page is just how I set it up.

What you need

  • Claude Code (desktop app or terminal) or Codex. It runs on the plan you already have; no API key.
  • Node.js 18 or newer. Check by typing node --version in a terminal. If it's missing, install it from nodejs.org.
  • Your project in a git folder. Floorplan reads the files git knows about.

1. Install it (once)

In any terminal:

claude plugin marketplace add haydenschmitty/floorplan
claude plugin install floorplan@floorplan

Then start a new Claude Code session. Plugins only load when a session starts. In VS Code, reloading the window does it (Ctrl+Shift+P → Developer: Reload Window).

Using Codex instead? Open Plugins → Add a marketplace, enter haydenschmitty/floorplan, and install Floorplan.

2. Make your map

  1. Open your project's folder in Claude Code.
  2. Ask: "Make me a floorplan of this app."
  3. Allow it to run its scripts when asked. A small app takes a few minutes; my app (about 500 files) took about three.
  4. The map opens in your browser.

3. Things to try on the map

  • Start here: a one-minute tour of the app.
  • Flows: step-by-step walkthroughs of what your app does.
  • The Ask bar: ask a real question, like "What happens when I tap Approve?" It reads your code and answers on the map. Then press Walk through and watch it step from card to card.
  • Health: a quick automatic check (very large files, keys written into code, open endpoints). Treat it as a first look, not a security audit.

Good to know

  • It doesn't change your code. It writes its own floorplan/ folder, which keeps itself out of git. After my run, git status showed nothing new.
  • At the end it asks whether future sessions should use the map. If you say yes, it adds a short note to CLAUDE.local.md, a personal file that also stays out of git.
  • If your server's routes are written in an unusual way, the map may not list them one by one. Mine didn't; everything else mapped fine.
  • After more work, just ask "update the floorplan". It only re-reads what changed.
