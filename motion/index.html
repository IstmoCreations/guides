10 motion effects that make a site feel designed

Each one is a single HTML file you can get from an AI with one prompt. Watch it play, copy its prompt, swap in your own words and colours.

The format is inspired by @zeeuiux's “50 Claude animations”. These effects are our own designs, built and tested by us. Not sponsored.

How to use them

  1. Copy a prompt (each one is complete on its own).
  2. Paste it into Claude (claude.ai or Claude Code) or another AI that writes code, and ask for one HTML file.
  3. Open the file in your browser. It plays and loops.
  4. Make it yours: change the line in [brackets] and the Brand part (colours and fonts).

Expect a close match, not a copy: every run comes out a little different.

"After" chip top left (squashes in as the wipe stops), "Before" chip top right. Then the button pulses once. [Swap in your own before page, your headline and your accent word.]

Setup: one self-contained HTML file with a 1200 x 900 stage, scaled to fit the browser window and centred. Animate with GSAP 3 (from a CDN) in ONE timeline about 3 s long that plays as soon as the fonts have loaded, holds the last frame for 1 s, and loops. Set starting states with gsap.set before the timeline. Easing words: "ease out" = power2.out, "glide" = power2.inOut, "lands" = back.out(2), "squash" = flatten to 118 % x 82 % in 0.12 s, then spring back with back.out(3). Drawn lines: give the path pathLength="1" and tween the stroke-dashoffset ATTRIBUTE (attr), not the CSS property. The pen: a copy of the path with stroke-dasharray 0 2, a round cap and a thick orange stroke, its stroke-dashoffset going 0 to -1 with the line's own timing, shown only while the line draws.

10 efectos de movimiento que hacen que un sitio se vea diseñado

Cada uno es un solo archivo HTML que puedes obtener de una IA con un prompt. Míralo en movimiento, copia su prompt y cambia las palabras y los colores por los tuyos.

El formato está inspirado en “50 Claude animations” de @zeeuiux. Estos efectos son diseños propios, hechos y probados por nosotros. Sin patrocinio.

Cómo usarlos

  1. Copia un prompt (cada uno está completo por sí solo).
  2. Pégalo en Claude (claude.ai o Claude Code) u otra IA que escriba código, y pide un solo archivo HTML.
  3. Abre el archivo en tu navegador. Se reproduce y se repite.
  4. Hazlo tuyo: cambia la línea entre [corchetes] y la parte de Brand (colores y fuentes).

Los prompts están en inglés; funcionan igual si pides la respuesta en español. Espera un resultado parecido, no una copia: cada intento sale un poco distinto.

On #111, one card (360 × 450, 26 px radius) made of four layers: background (#2e2e2e), layout (dashed grey boxes), content (orange image and text bars), action (white "Book a call" pill). Shown flat first. Then every layer glides to rotateX 68° / rotateZ −45° at 86 % scale, and the layers spread apart vertically, 170 px each, by moving their wrappers, not along Z, so they never overlap. Thin dashed grey lines then join the matching corners top to bottom, so it reads as one card pulled apart (measure the corners in the end pose and draw straight lines between them). Labels on the right line up with each layer: 04 Action, 03 Content, 02 Layout, 01 Background, each with a grey leader line and an orange serif-italic number. Corner label "Anatomy · Booking card". [Swap in your own card and its four layer names.]

Setup: one self-contained HTML file with a 1200 x 900 stage, scaled to fit the browser window and centred. Animate with GSAP 3 (from a CDN) in ONE timeline about 3 s long that plays as soon as the fonts have loaded, holds the last frame for 1 s, and loops. Set starting states with gsap.set before the timeline. Easing words: "ease out" = power2.out, "glide" = power2.inOut, "lands" = back.out(2), "squash" = flatten to 118 % x 82 % in 0.12 s, then spring back with back.out(3). Drawn lines: give the path pathLength="1" and tween the stroke-dashoffset ATTRIBUTE (attr), not the CSS property. The pen: a copy of the path with stroke-dasharray 0 2, a round cap and a thick orange stroke, its stroke-dashoffset going 0 to -1 with the line's own timing, shown only while the line draws.

Fonts: Public Sans 400/600/800 for everything, Source Serif 4 Italic for the one emphasised word, both from Google Fonts.
