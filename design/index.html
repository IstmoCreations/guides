The design setup that beat Astryx

What my Claude Code used in the blind test, how to install it in two minutes, and how to test any design tool on your own work before you trust it (including this one).

The test, in short

Three AI builders, same model, same three jobs (a dashboard, a landing page, a phone app): plain Claude Code with nothing added, Claude Code with my setup, and Claude Code with Meta's Astryx. OpenAI's Codex ranked the screenshots blind, under shuffled letters.

Total score (of 120)Rounds won
My setup: 104dashboard, landing page
Plain Claude Code: 102phone app
Claude Code + Astryx: 73none

Read it for what it is. One run per builder, one judge, first screens only. My setup beat plain Claude by 2 points, which is close. It also took 2 to 5 times longer. Astryx is in beta and built for big teams keeping hundreds of screens consistent, which one page can't test. To be fair to it, its pages respected the phone's "reduce animations" setting, and plain Claude's phone app didn't.

What my setup used for design

  1. frontend-design, Anthropic's official design skill. It pushes the AI to pick a real visual direction instead of the default template look. Free.
  2. Impeccable's automatic check, by Paul Bakaus. After every file the AI writes, it scans for common "AI-made" design mistakes and tells the AI what to fix. Free, Apache-2.0.
  3. A short list of CSS techniques I collected and tested (glass panels, glows, responsive layouts). I call it ui-tricks, and it was used in one round only. Each trick was checked in Chrome and Firefox; see them all on one page.

That's it for design. The prompt only said: "use the design skills installed in this setup as you see fit."

Install it (Claude Code)

Type these in a Claude Code session, one at a time:

/plugin install frontend-design@claude-plugins-official
/plugin marketplace add pbakaus/impeccable
/plugin install impeccable@impeccable

For ui-tricks, paste this into Claude Code and it installs itself:

Download https://istmocreations.github.io/guides/design/ui-tricks/SKILL.md and save it as ui-tricks/SKILL.md in my personal Claude Code skills folder (~/.claude/skills/). Show me the path when done.

Restart Claude Code. Then ask for any page and add: "use the frontend-design skill".

Optional: Impeccable's full process

I also ran a fourth builder: my setup told to use Impeccable's whole build, critique and polish process. It won the phone app, but it took up to 25 minutes a job and several times the AI usage. I use it for a page that really matters, not for everything. Ask for it by name: "build this with the impeccable skill, then critique and polish it".

Test any tool yourself (10 minutes)

Before you add a tool because a reel told you to, give your AI the same job twice and compare. Run this in two fresh sessions, one with the tool and one without, then show both screenshots to a different AI that doesn't know which is which.

Build a single-page [what you actually need: a booking page for my gym / a menu for my café / ...] in one HTML file. Real content, no lorem ipsum, works on a phone. Make it look as good as you can.
Two screenshots of the same page, built by two different setups, labelled A and B. Score each 1-10 on: looks professional, easy to read, fits the business, works on a phone. Say which you would ship and why, in three lines. Don't guess who built which.

La configuración de diseño que le ganó a Astryx

Lo que usó mi Claude Code en la prueba a ciegas, cómo instalarlo en dos minutos y cómo probar cualquier herramienta de diseño con tu propio trabajo antes de confiar en ella (incluida esta).

La prueba, en corto

Tres constructores de IA, mismo modelo, los mismos tres trabajos (un panel, una landing page y una app de teléfono): Claude Code sin nada, Claude Code con mi configuración, y Claude Code con Astryx de Meta. Codex, de OpenAI, ordenó las capturas a ciegas, con letras mezcladas.

Puntaje total (de 120)Rondas ganadas
Mi configuración: 104panel, landing page
Claude Code sin nada: 102app de teléfono
Claude Code + Astryx: 73ninguna

Léelo como lo que es. Una corrida por constructor, un juez, solo la primera pantalla. Mi configuración le ganó a Claude sin nada por 2 puntos, que es poco. Además tardó de 2 a 5 veces más. Astryx está en beta y está hecho para equipos grandes que mantienen cientos de pantallas iguales, algo que una sola página no prueba. Para ser justos: sus páginas respetaron el ajuste del teléfono de "reducir animaciones", y la app de Claude sin nada no.

Lo que usó mi configuración para diseño

  1. frontend-design, la skill oficial de diseño de Anthropic. Empuja a la IA a elegir una dirección visual real en vez del look de plantilla. Gratis.
  2. La revisión automática de Impeccable, de Paul Bakaus. Después de cada archivo que escribe la IA, busca errores típicos de diseño "hecho por IA" y le dice qué corregir. Gratis, Apache-2.0.
  3. Una lista corta de técnicas CSS que junté y probé (paneles de vidrio, brillos, diseños adaptables). La llamo ui-tricks y se usó en una sola ronda. Cada técnica se probó en Chrome y Firefox; míralas todas en una página.

Eso es todo en diseño. El prompt solo decía: "usa las skills de diseño instaladas como mejor te parezca".

Instálalo (Claude Code)

Escribe esto en una sesión de Claude Code, uno por uno:

/plugin install frontend-design@claude-plugins-official
/plugin marketplace add pbakaus/impeccable
/plugin install impeccable@impeccable

Para ui-tricks, pega esto en Claude Code y se instala sola:

Descarga https://istmocreations.github.io/guides/design/ui-tricks/SKILL.md y guárdalo como ui-tricks/SKILL.md en mi carpeta personal de skills de Claude Code (~/.claude/skills/). Muéstrame la ruta al terminar.

Reinicia Claude Code. Luego pide cualquier página y agrega: "usa la skill frontend-design".

Opcional: el proceso completo de Impeccable

También corrí un cuarto constructor: mi configuración usando todo el proceso de Impeccable (construir, criticar y pulir). Ganó la app de teléfono, pero tardó hasta 25 minutos por trabajo y varias veces el uso de IA. Lo uso para una página que de verdad importa, no para todo. Pídelo por nombre: "construye esto con la skill impeccable, luego critícalo y púlelo".

Prueba cualquier herramienta tú mismo (10 minutos)

Antes de agregar una herramienta porque un reel te lo dijo, dale a tu IA el mismo trabajo dos veces y compara. Córrelo en dos sesiones nuevas, una con la herramienta y otra sin ella, y muéstrale las dos capturas a otra IA que no sepa cuál es cuál.

Construye una página [lo que de verdad necesitas: una página de reservas para mi gimnasio / un menú para mi café / ...] en un solo archivo HTML. Contenido real, nada de lorem ipsum, que funcione en un teléfono. Hazla lo más bonita que puedas.
Dos capturas de la misma página, hechas por dos configuraciones distintas, marcadas A y B. Califica cada una del 1 al 10 en: se ve profesional, fácil de leer, va con el negocio, funciona en un teléfono. Di cuál publicarías y por qué, en tres líneas. No adivines quién hizo cuál.
