Frosted glassVidrio esmeriladoIN THE REELEN EL REEL

The panel blurs whatever is behind it, and your text on it stays sharp (Apple / Android style).

El panel desenfoca lo que hay detrás y tu texto encima queda nítido (estilo Apple / Android).

Frosted glassThe background blurs. This text stays sharp.
.glass {
  background: rgb(255 255 255 / .16);
  -webkit-backdrop-filter: blur(24px) saturate(1.4);
  backdrop-filter: blur(24px) saturate(1.4);
  border: 1px solid rgb(255 255 255 / .35);
  border-radius: 28px;
}

Tip: filter: blur() would blur your text too; backdrop-filter blurs only what is behind. saturate keeps the colours from going grey.

Tip: filter: blur() también desenfocaría tu texto; backdrop-filter solo desenfoca lo de atrás. saturate evita que los colores se vuelvan grises.

Ambient sparkles, one elementDestellos de fondo, un solo elemento

Three dot grids drifting at three speeds read as depth. No extra HTML, no images.

Tres rejillas de puntos moviéndose a tres velocidades se leen como profundidad. Sin HTML extra, sin imágenes.

.sparkle {
  background-color: #0b0b14;
  background-image:
    radial-gradient(circle, #fff 1px, transparent 1.5px),
    radial-gradient(circle, #ffd6a5 1px, transparent 1.5px),
    radial-gradient(circle, #ff9fd0 1.5px, transparent 2px);
  background-size: 60px 60px, 90px 90px, 140px 140px;
  background-position: 0 0, 30px 40px, 70px 20px;
  animation: drift 12s linear infinite;
}
@keyframes drift {
  to { background-position: 60px 60px, -60px 130px, 210px -120px; }
}
@media (prefers-reduced-motion: reduce) {
  .sparkle { animation: none; }
}

Tip: move each layer by a whole number of its own tiles (60, 90, 140) or the loop jumps.

Tip: mueve cada capa un número entero de sus propias baldosas (60, 90, 140) o el ciclo salta.

Cover glow, made from the picture itselfBrillo de portada, hecho con la misma fotoIN THE REELEN EL REEL

The glow is a blurred copy of the picture, so it always matches. Change the photo and the glow follows.

El brillo es una copia desenfocada de la foto, así que siempre combina. Cambia la foto y el brillo la sigue.

Tap the picture to change it.

Toca la imagen para cambiarla.

.cover {
  position: relative; isolation: isolate;
  background: var(--img) center / cover;
}
.cover::before {
  content: ""; position: absolute; inset: 0;
  z-index: -1; border-radius: inherit;
  background: inherit;              /* literally the same image */
  filter: blur(34px) saturate(1.8);
  scale: 1.18;
}

Tip: don't give the cover a z-index, opacity or transform, or the glow paints on top of it.

Tip: no le pongas z-index, opacity ni transform a la portada, o el brillo se pinta encima.

Never a PNG for a cut-out photoNunca un PNG para una foto recortada

JPEG can't do transparency, PNG can but is huge. WebP and AVIF do both. Measured on the same cut-out photo:

JPEG no tiene transparencia; PNG sí, pero pesa muchísimo. WebP y AVIF hacen ambas cosas. Medido con la misma foto recortada:

Fluid type with clamp()Texto fluido con clamp()

The heading grows with the screen but never below 2rem or above 5rem. Turn your phone sideways to see it change.

El título crece con la pantalla pero nunca baja de 2rem ni pasa de 5rem. Gira tu teléfono para verlo cambiar.

Type that scales smoothly

.fluid {
  font-size: clamp(2rem, 6vw, 5rem);
  text-wrap: balance;
}

Watch out: vw follows the window, not the box. Inside a narrow panel, use a container query (16).

Ojo: vw sigue a la ventana, no a la caja. Dentro de un panel angosto, usa una container query (16).

The fix: a panel that checks its own widthEl arreglo: un panel que mide su propio anchoIN THE REELEN EL REEL

A container query reads the box's width, not the screen's, so a panel stops breaking when it gets narrow inside a wide window. Media queries can't see that.

Una container query lee el ancho de la caja, no el de la pantalla, así que un panel deja de romperse cuando queda angosto dentro de una ventana ancha. Las media queries no pueden ver eso.

Stacked when its box is narrow, side by side when it is wide.Apilado cuando su caja es angosta, lado a lado cuando es ancha.
.wrap { container-type: inline-size; }

@container (min-width: 300px) {
  .item { flex-direction: row; }
}

Measured trap: the container must get its width from outside. Inside a shrink-to-fit parent it collapses to 0px. Give it width: 100%, a 1fr track or flex: 1.

Trampa medida: el contenedor debe recibir su ancho de afuera. Dentro de un padre que se encoge al contenido colapsa a 0px. Dale width: 100%, una pista 1fr o flex: 1.

Una línea: nunca más ancho que unos cómodos 65 caracteres, siempre a 1rem de los bordes, centrado. Toda esta página lo usa.
